# nick-we.com

This is the code repository for my personal website [nick-we.com](https://nick-we.com).

The site serves as my platform to share insights, tutorials, and thoughts on:
*   **Software Engineering:** Best practices, architecture, and design patterns.
*   **Testing:** Methodologies like Boundary Value Analysis and test automation.
*   **Go (Golang):** Deep dives into language features, static analysis, and tooling (e.g., SSA)

Built with [Hugo](https://gohugo.io/) and the [Hextra](https://github.com/imfing/hextra) theme.
